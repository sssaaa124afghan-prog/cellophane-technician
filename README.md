# فني ماكينة السلوفان SICI

أداة ويب (ملف واحد) لظبط ماكينة تغليف السلوفان Wuxi SICI عند تغيير مقاس البوكس.

- اكتب طول وعرض وارتفاع البوكس، وتطلع ظبطة كاملة بالترتيب: القالب، المسافات، عرض الرول، Film length، الحرارة، الهوا، والسرعات.
- صور أجزاء الماكينة جوه الأداة.
- كارت قالب مطبوع مقاس A5.
- مصلّح العيوب.
- البيانات بتتحفظ على الجهاز، ومعاها نسخة احتياطية JSON.

التشغيل: افتح `index.html` في أي متصفح.

> ملاحظة: الحرارة وضغط اللحام وعرض الرول بدايات تقديرية تتأكد على الماكينة.
